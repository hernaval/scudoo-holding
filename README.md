## 🛠 Getting Started

### Prerequisites
* **Node.js** (Version 18.0 or higher recommended)
* **npm** or **yarn**

### Installation
1.  **Clone the repository:**
    ```bash
    git clone https://github.com/hernaval/scudoo-holding.git
    ```
2.  **Navigate to the directory:**
    ```bash
    cd scudoo-holding
    ```
3.  **Install dependencies:**
    ```bash
    npm install
    ```

---

## 🚀 Available Scripts

| Script | Description |
| :--- | :--- |
| `npm run dev` | Runs the app in development mode at `http://localhost:3000`. |
| `npm run build` | Builds the app for production to the `dist` folder. |
| `npm run preview` | Serves the production build locally for testing. |
| `npm run lint` | Analyzes code for potential errors and styling issues. |
